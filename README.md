# Door Sheet PDF Generator 🚪📄

This application generates PDF files for door sheets.
For the best experience, this project is designed to be run using **Visual Studio Code (VS Code)**.

---

## 🛠 Prerequisites (Step-by-Step Setup)

Before using the app, you need to install two programs: **VS Code** and **Python**.

### 1. Download & Install VS Code
Visual Studio Code is the editor where we will run the project.

* **Visit the website:** Go to [code.visualstudio.com](https://code.visualstudio.com/).
* **Download:** Click the big blue **"Download"** button.
* **Install:**
    * **Windows:** Run the installer, keep default settings, and click "Next".
    * **macOS:** Unzip the file and drag the "Visual Studio Code" app into your **Applications** folder.

### 2. Download & Install Python
Python is the language running the logic behind the app.

* **Visit the website:** Go to [python.org/downloads](https://www.python.org/downloads/).
* **Download:** Click the button "Download Python 3.x.x".
* **Install:**
    * **⚠️ Windows Users (Important):** When the installer opens, **check the box** at the bottom that says **"Add Python to PATH"** before clicking "Install Now".
    * **macOS Users:** Run the installer and follow the instructions.

---

## ⚙️ Setting Up the Project

### 1. Install the Python Extension in VS Code
1.  Open **VS Code**.
2.  Click on the **Extensions** icon in the left sidebar (or press `Ctrl+Shift+X`).
3.  Search for **"Python"**.
4.  Click **Install** on the first result (created by Microsoft).

### 2. Open the Project Folder Correctly
1.  Download and unzip this project.
2.  In VS Code, go to **File** -> **Open Folder...** (or **Open...** on Mac).
3.  Select the **entire folder** containing these files.
    * *✅ You must open the folder, not just the `app.py` file.*

### 3. Open the Terminal
1.  In the top menu bar, click **Terminal** -> **New Terminal**.
2.  A panel will appear at the bottom. This is where you type the commands below.

---

## 🚀 Installation & Launch

Run these commands inside the **VS Code Terminal**.

### Step 1: Install Dependencies
Copy and paste this command to install the necessary libraries:

```bash
pip install -r requirements.txt

```
### Step 2: Run the App
Start the application using the command for your system:

Windows:

```bash
python app.py
```
macOS:

```bash
python3 app.py
```

### Step 3: Open in Browser
Once the app is running, you will see a message in the terminal.

Go to this address: http://127.0.0.1:5000
