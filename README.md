# Door Sheet PDF Generator

A simple local web app that generates Door Sheet PDFs.

---

## What you need (requirements)

- **Python 3.10+** (recommended: 3.11 or 3.12)
- Internet connection (only to install dependencies the first time)
- (Optional) VS Code if you want to edit the code

---

## Quick start (overview)

1. Install dependencies
2. Run the app
3. Open in browser: http://127.0.0.1:5000

---
